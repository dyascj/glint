The first release of Glint, a fast launcher for macOS written in Rust.

- Root search across apps, files, commands, System Settings panes, quicklinks and extensions, with learned ranking, aliases and per-command hotkeys.
- Calculator with percentages and unit conversion, plus Calculator History.
- Clipboard History with pinning and a preview pane.
- Pick Color, Saved Colors, inline color conversion and shade ramps.
- Emoji & Symbols, Quicklinks, Snippets and system commands.
- Extensions: script commands in any language, including a searchable list mode.
- Onboarding, a menu bar item, Settings, and signed one-click updates.
