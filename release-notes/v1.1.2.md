Glint 1.1.2 is a quality release: safer data, sturdier extensions, a smarter calculator, and a mark that matches the new icon.

- **Your data is safer.** If a settings or history file can't be read (say, after a hand edit), Glint moves it to `name.bad.json` instead of overwriting it. Saves are flushed to disk, and Glint and its Settings window can no longer garble a file by saving at the same moment.
- **Extensions that hang get stopped.** The time limit now stops the whole script, including pipelines and background processes it started. A script that leaves something running no longer holds up its result, and huge or non-UTF-8 output can't swamp the launcher.
- **List extensions ignore warnings.** A list extension that prints warnings on stderr (Node deprecation notices, for example) still shows its items.
- **Calculator fixes.** `-2^2` is -4, `max(1,234)` is 234, not 1234, and conversions that overflow show nothing instead of "inf".
- **Colors keep transparency.** HSL, OKLCH and SwiftUI output include alpha, and `oklch()` with a percent chroma uses the CSS scale.
- **Hotkeys record correctly on every keyboard layout.** The recorder records the key you pressed on AZERTY and other layouts, handles combinations like ⌃⇧1 and the arrow keys, and ⌘W or ⌘Q no longer close Settings while you record them.
- **The right item, every time.** Deleting or pinning a clipboard entry from ⌘K hits that entry even if a new copy arrives while the panel is open, and an extension's argument form runs that extension even if the Extensions folder changes meanwhile.
- **⌘↵ is predictable.** It no longer quits an app in Switch Windows or toggles a favorite; those keep their own shortcuts.
- File search can't get stuck behind a stalled Spotlight query.
- Snippets paste `{date}` and other braces in your clipboard as typed.
- Open at Login is set up even when you choose Set up later in onboarding.
- About says so when an update check couldn't reach GitHub, instead of claiming you're up to date.
- A failed update always cleans up after itself.
- The Accessibility explanation now covers Search Menu Items and Switch Windows.
- The mark in the menu bar, About, Settings and onboarding is now the keycap from the app icon.
