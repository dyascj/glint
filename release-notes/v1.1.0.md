Glint 1.1 reaches into the apps you use, remembers images, and does less work on every keystroke.

- **Search Menu Items.** Search every command in the menu bar of the app you were just in, with its shortcut, and run it with Return. Needs Accessibility.
- **Switch Windows.** Every open window across your apps, frontmost first, including minimized ones. Needs Accessibility.
- **Favorites.** Press ⌘⇧F on any app, command, extension or quicklink to pin it to the top of the empty search. Reorder them from ⌘K.
- **Images in Clipboard History.** Screenshots and copied pictures are kept with a thumbnail and a large preview, and paste back as images.
- **Time zones in the calculator.** `time in tokyo`, `london time`, `3pm pst in berlin`. Cities come from macOS's own time zone list.
- Root search builds full rows only for the results it shows, so each keystroke takes about half the work.
- Opening the launcher no longer waits on an Applications folder rescan.
- File results stay on screen while the next search runs, and the selection stays put when they arrive.
- Opening links, revealing files and running quick system commands no longer pause the launcher.
- The emoji grid and long clipboard entries are much lighter to draw.
- Resetting rankings in Settings now sticks.
- Extension icons given as an image path show the image itself.
