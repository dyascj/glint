Glint now speaks SF Pro, and every icon in search is a symbol.

- SF Pro throughout the launcher, Settings and onboarding. SF Mono stays for keycaps, script output and code.
- Quicklinks, extensions and extension list items use SF Symbols, in the same tiles as built-in commands. An extension's `icon` is now an SF Symbol name or an image path.
- A hotkey on a quicklink without `{query}` now opens it.
- The emoji and color grids keep your selection while things load in the background.
- With the actions panel open, moving the mouse no longer changes which item the actions apply to.
- Search Files fetches its full set of results after a root search for the same text.
- The Settings and Onboarding windows no longer undo each other's changes.
- Extension views keep pointing at the right script when the Extensions folder changes.
- Copied files in clipboard history paste as files again.
- Saved colors show in your chosen color format.
