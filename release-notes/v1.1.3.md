Glint 1.1.3 fixes an empty window that could appear after using Glint.

- **No more empty panel after Pick Color.** Picking a color (or cancelling the eyedropper) could leave a blank, blurred launcher window on screen that wouldn't go away. The color is copied and the launcher stays closed.
- The same empty panel could appear behind an update alert, after Unhide All Hidden Apps, or when opening Glint.app from Finder while it was already running. Opening Glint.app now shows the launcher as it should.
